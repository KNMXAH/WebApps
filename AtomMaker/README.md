# 원자 만들기 (Atom Builder) 웹앱

> **입자를 조작하며 스스로 발견하는 원자의 세계**
>
> 중학생 대상 원자 구조 학습용 웹 기반 인터랙티브 시뮬레이터임.

## 프로젝트 소개

**원자 만들기(Atom Builder)** 웹앱은 중학교 과학 교과과정의 원자 및 이온 개념을 학생들이 직접 입자를 조작하는 암묵적 경험(Implicit Learning)을 통해 체득할 수 있도록 설계한 웹 앱임.

AR(증강현실) 웹앱을 통해 원자의 모습을 입체적으로 관찰한 후, 본 앱에서 **양성자, 중성자, 전자**를 조합하여 안정된 원자와 이온을 직접 완성해 볼 수 있음.

### 이 앱을 통해 스스로 깨닫게 되는 3가지 개념

1. **원자의 종류를 결정하는 것은 양성자의 개수임.** (전자나 중성자가 아님)

2. **중성자는 많은 수의 양성자가 뭉쳐있을 때 원소를 안정하게 유지시킴.**

3. **입자들을 아무렇게나 조합할 수 없으며, 원자를 안정화시키는 조건이 존재함.**

> **디자인 철학**: 화면에 직관적인 개념 설명 텍스트를 일절 노출하지 않음. 오직 학생의 입자 조작 결과(원소 기호 변화, 이온식, 튕겨나가는 입자 등)로만 자연스러운 탐구가 이루어짐.

## 주요 기능 및 특징

* **아이패드 및 터치스크린 최적화**: Pointer Events API 적용으로 iPad Safari, Chrome 등에서 손가락 드래그&드롭을 매끄럽게 지원함.

* **원자번호 1~20번(H~Ca) 지원**: 중학교 과학 교육과정 범위 내의 주요 원소 표기법 및 이온화 규칙을 적용함.

* **3단계 핵 안정성 시스템**:

  * **영구 안정 상태 (**$N=Z$**)**: 원자가 깨지지 않고 영구적으로 형태를 유지함. (수소 $H$는 $N=0, 1$ 모두 안정함)

  * **시한부 안정 상태 (**$N=Z \pm 1$**)**: 5초 동안 상태를 유지하며 추가 조작 기회를 제공함. 5초 내 조치가 없으면 잉여 입자가 튕겨 나감.

  * **불안정 상태**: 허용 범위를 벗어난 조합은 3초 후 잉여 양성자/중성자가 튕겨 나가 소멸함.

* **실시간 이온식 및 전자 궤도 물리 연출**:

  * 전하량($e^- - p^+$)에 따라 $Na^+$, $Mg^{2+}$, $O^{2-}$, $Cl^-$ 등의 이온식이 상단에 실시간 갱신됨.

  * 양이온 상태일 때는 멀리 놓인 전자가 원자핵으로 정전기적 이끌림을 받으며 끌려옴.

  * 음이온 한계(전자 임계값)를 초과하여 전자를 넣으면 궤도를 돌던 전자가 차례대로 튕겨 나감.

* **의존성 없는 단일 파일 (Single HTML)**: 별도의 서버 구축이나 외부 라이브러리 설치 없이 HTML 파일 하나만 브라우저로 열면 즉시 실행됨.

## 이용 방법 및 조작 가이드

1. **양성자(Red, `+`) 꺼내기**: 화면 우측 사이드바에서 양성자를 드래그하여 중앙으로 꺼내 놓으면 원자핵과 불투명한 원자 영역이 형성되고 원소 기호가 나타남.

2. **중성자(White) 추가하기**: 양성자 수가 많아지면 중성자를 추가하여 핵을 안정화해야 함.

3. **전자(Blue, `-`) 배치하기**: 화면 영역에 전자를 놓아 원자핵 주변 궤도로 끌어당김. 전자 수와 양성자 수의 차이에 따라 상단에 이온식(예: $Li^+$)이 표시됨.

4. **리셋(Reset)**: 언제든 좌측 상단의 버튼을 눌러 초기 상태로 되돌리고 다른 원소를 만들어볼 수 있음.

## 시작하기 (실행 방법)

### 웹에서 바로 실행하기 (GitHub Pages)

1. Repository의 `index.html` 링크를 통해 바로 접근 가능함.

2. 또는 로컬에 다운로드하여 브라우저에서 직접 파일(`index.html`)을 더블 클릭해 실행할 수 있음.

### 로컬 실행

```
# Repository 클론
git clone https://github.com/KNMXAH/WebApps.git

# 폴더 이동 후 index.html 브라우저 실행
cd AtomMaker
open index.html
```

## 프로젝트 구조

```
AtomMaker/
├── index.html              # 실행 가능한 단일 HTML 웹앱 (Canvas / CSS )
├── app.js                  # 웹앱 JS 
└── README.md               # 프로젝트 안내 문서
```

## 기술 스택 (Tech Stack)

* **Language**: HTML5, CSS3, JavaScript (ES6+)

* **Rendering**: HTML5 Canvas 2D Context

* **Events**: Pointer Events API (`pointerdown`, `pointermove`, `pointerup`)

* **Compatibility**: iPad Safari, Chrome, Edge 및 모든 모바일/데스크톱 브라우저
