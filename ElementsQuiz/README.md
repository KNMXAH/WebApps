# 화학 원소기호 맞히기 퀴즈 웹앱 (Element Quiz Web App)

학생들이 화학 원소 기호와 이름을 쉽고 재미있게 학습할 수 있도록 제작된 인터랙티브 게이미피케이션 학습 도구입니다.

---

## 1. 앱 개요 및 주요 특징

* **목적**: 화학 원소기호 암기가 필요한 학생들을 위한 자기주도 학습 및 교실 내 실시간 퀴즈 진행
* **주요 특징**: 
  * 외부 이미지나 무거운 에셋 없이 **Web Audio API**를 활용한 동적 효과음(정답 사운드, 오답 비프음, 타이핑 타격감)과 **CSS 애니메이션**을 통한 인터랙션 제공
  * **Firebase Firestore**의 실시간 리스너를 활용해 교실 환경에서 지연 없는 실시간 대전(멀티 모드) 지원

---

## 2. 핵심 모듈별 상세 기능

| 구분 | 주요 기능 | 세부 설명 |
| :--- | :--- | :--- |
| **인증 시스템** | 가상 도메인 로그인 | 학번 및 이름 기반의 아이디를 입력받아 내부적으로 도메인과 연동하여 Firebase Auth 처리 |
| **싱글 모드** | 개인 학습 퀴즈 | 원소기호 모드, 원소 모드, 혼합 모드를 지원하며 최고 점수를 Firebase에 안전하게 기록 및 갱신 |
| **멀티 모드** | 실시간 교실 대전 | - **교사(방장)**: QR 코드 생성, 방 생성, 모드 및 시간 설정, 게임 시작 및 강제 종료 제어<br>- **학생**: 실시간 순위판 동기화, 결정론적 해시 알고리즘을 통한 공정한 문제 시퀀스 제공 |
| **인터랙션** | 타격감 및 피드백 | - 정답 및 오답 시 화면 흔들림 및 파티클 폭발 효과 제공<br>- Web Audio API를 활용한 맞춤형 효과음 재생 |
| **랭킹 시스템** | 모드별 리더보드 | 각 학습 모드별로 점수를 분류하여 상위 10명의 순위를 실시간 조회 |

---

## 3. 기술 스택

* **Frontend**: HTML5, Tailwind CSS, JavaScript (ES6+)
* **Backend & Database**: Firebase Authentication, Cloud Firestore
* **Utilities**: QRCode.js (QR 코드 생성), Web Audio API (오디오 효과음 합성)
