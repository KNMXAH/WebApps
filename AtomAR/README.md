# 중학생을 위한 웹 기반 원자 AR 관찰 시스템 (Atom AR Explorer)

## 1. 개요
본 애플리케이션은 웹 브라우저와 웹캠을 활용하여 별도의 프로그램 설치 없이 증강현실(AR) 환경에서 3차원 원자 구조를 관찰할 수 있도록 구현된 교육용 웹 어플리케이션임. 표준 Hiro 마커 인식을 기반으로 중학교 과학 교육과정의 원자 구조(원자핵, 양성자, 중성자, 전자)를 시각적으로 학습할 수 있음.

## 2. 주요 기능
* **마커 기반 AR 렌더링**: A-Frame 및 AR.js 라이브러리를 활용하여 실시간 웹캠 영상 위에 3차원 원자 모델을 정밀하게 배치 및 렌더링함.
* **동적 원자 구조 생성**: 
  * 애플리케이션 실행 시 무작위로 결정되는 양성자 수(1~4개)에 따라 원자핵과 전자가 동적으로 생성됨.
  * 구면 피보나치 알고리즘(Spherical Fibonacci)을 적용하여 원자핵을 구성하는 핵자(양성자 및 중성자)를 밀집된 구체 형태로 시각화함.
  * 양성자 수에 상응하는 전자가 각각 상이한 궤도와 회전 속도로 원자핵 주변을 공전함.
* **거리 반응형 투명도 제어**: 카메라와 원자 간의 거리를 실시간으로 연산하여 원자의 전체 크기 범위를 나타내는 외곽 구체 껍질의 투명도를 조절함. 카메라 근접 시 껍질이 투명해지며 내부 구조 관찰이 용이해짐.
* **실제 크기 비율 비교 모드**: UI 상단의 `Real Size` 토글 기능을 통해 원자 전체 크기와 원자핵 및 전자 간의 극단적인 상대적 크기 비율을 비교 체험할 수 있음.
* **열운동 시각화**: 원자 객체에 미세 진동 효과를 부여하여 물리적 열운동 상태를 모사함.

## 3. 기술 스택
* **Core**: HTML5, CSS3, JavaScript (ES6+)
* **3D Graphics Framework**: A-Frame (v1.4.2)
* **Augmented Reality Library**: AR.js (v3.3.2)
* **Mathematical / Vector Computation**: Three.js

## 4. 설치 및 실행 방법
본 애플리케이션은 별도의 빌드 과정이 필요 없는 단일 HTML 파일 기반의 구조를 가짐.

1. 소스 코드를 `index.html` 파일로 저장함.
2. 로컬 웹 서버 환경(예: Python HTTP Server 또는 VS Code Live Server)을 통해 실행함.
   ```bash
   python -m http.server 8000
   ```
3. 지원되는 웹 브라우저(Chrome, Safari 등)를 통해 접속하고 웹캠 권한을 허용함.
4. Hiro 마커 이미지를 디스플레이에 출력하거나 인쇄하여 카메라에 인식시킴.

## 5. 교육적 활용 방안
* 중학교 과학 교과 내 '원자의 구조' 단원 학습 시 추상적인 개념을 공간적·시각적으로 이해하는 데 기여함.
* 마이크로 코스모스의 구조적 특징과 원자 내부의 거대한 빈 공간 비율을 직관적으로 학습할 수 있음.
